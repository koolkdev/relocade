# Text font

`modern-dos-8x8.bin` contains all 256 CP437 glyphs from **Modern DOS 8x8**
version 20190101.02 by Jayvee Enaguas, released under CC0 1.0.
The license is included in `modern-dos-LICENSE.txt`.

Source: [ModernDOS8x8.ttf in PC Face](https://github.com/susam/pcface/blob/8629ba46b73f58ac88cacbe8e77c6e9975dd221c/src/font/moderndos/ModernDOS8x8.ttf).
The font was rasterized without antialiasing at 16 pixels per em into 8-by-8
cells, using PC Face's CP437-to-Unicode mapping. Character zero is blank.

The file is 2,048 bytes: eight rows per glyph in character-code order, with
the leftmost pixel in bit 7. Its SHA-256 is
`9b7f5c3765e8526ae96265aad4c2f5486a8e74b33c553816859a5835427c5ff1`.
